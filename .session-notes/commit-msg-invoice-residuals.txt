refactor(frontend): drop last `as Invoice` cast and `useState<any>` in invoice page

Closes the last typed-contract residual in
`frontend/app/invoice/[id]/page.tsx`. Surgical mirror of the pay-page
cleanup landed in commit `3cc93b4` — both shapes (state-shape `any`
and `as Invoice` cast on `result.data`) are retired in a single
atomic edit. After this commit:

- `paymentInfo` is `useState<PaymentSession | null>(null)` (was
  `useState<any>(null)`).
- `setInvoice(invoiceResult.data)` is uncast (was
  `setInvoice(invoiceResult.data as Invoice)`).
- `setPaymentInfo(paymentResult.data)` becomes compile-time-checked
  end-to-end against `Promise<ApiResponse<PaymentSession>>` from the
  already-typed `api.getPaymentInfo`.

Both API methods were retuned to typed `Promise<ApiResponse<T>>` returns
in commit `8e1a1f7` (PR "close typed-state end-to-end"), so the cast
already represents dead work — the call site was strictly a typing-
defeater that lingered past the discriminated-union landing in
`357873c`. This commit ends the residue at the invoice page's
useState and result.data boundaries in the same shape `3cc93b4` did
for the pay page.
